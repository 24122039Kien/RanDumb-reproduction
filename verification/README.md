# Kiểm chứng với code gốc

Thư mục này chứa script clone và chạy code của tác giả cho E9.

- Không đưa code của tác giả vào repo. Repo gốc dùng giấy phép GPL-3.0.
- Clone vào `verification/_official/`, thư mục này đã nằm trong `.gitignore`.
- Ghim theo một commit cụ thể và ghi commit đó vào W&B.
- Log các run với thẻ `official-code`.
